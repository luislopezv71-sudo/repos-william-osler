## 🎯 Objetivos del Repositorio

1. **Desarrollo Web & Simuladores:** Alojar aplicaciones cliente (HTML/CSS/JS) y simuladores en HTML Canvas para la enseñanza gamificada de Matemáticas e Informática.
2. **Computación & Data Science:** Proporcionar scripts en Python y Jupyter Notebooks para análisis estadístico, procesamiento de datos e ingeniería de prompts.
3. **Digitalización & IA Aplicada:** Integrar Inteligencia Artificial Generativa (IA) en la educación universitaria mediante prompts estructurados de 5 elementos.
4. **Investigación Académica:** Ofrecer guías estructuradas y delimitaciones de investigación para tesinas en la región de Zihuatanejo de Azueta y el Distrito Judicial de Azueta.
