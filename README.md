## 🎯 Objetivos del Repositorio

1. **Digitalización & IA Aplicada:** Integrar tecnologías emergentes e Inteligencia Artificial Generativa (IA) en la educación universitaria mediante prompt engineering de 5 elementos (Rol, Contexto, Tarea, Formato, Restricción).
2. **Investigación Académica:** Ofrecer guías estructuradas y delimitaciones de investigación para la elaboración de tesinas en la región de Zihuatanejo de Azueta y el Distrito Judicial de Azueta.
3. **Recursos Didácticos:** Proporcionar instrumentos de evaluación, simuladores interactivos, exámenes prácticos y plantillas para estudiantes de nivel superior.
